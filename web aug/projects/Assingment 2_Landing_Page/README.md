# GlowCare - Responsive Product Landing Page

A beginner-friendly responsive product landing page created for Web Development Week 02 Minor Project.

## Product
GlowCare Face Serum

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Basic Tailwind CSS

## Sections
- Navigation Bar
- Hero Section
- Features
- Benefits
- Customer Reviews
- Pricing / Call-to-Action
- Footer

## How to Run
1. Download or clone the project.
2. Open `index.html` in a web browser.

No JavaScript is required.
